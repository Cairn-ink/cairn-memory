? Where should memory live? (1/2)
Memory stays on this computer. Setup sends no user data.
The upgraded local engine sends memory text to OpenAI for embeddings when
  saving, correcting or importing memories. Semantic recall sends the recall
  query for embeddings. These requests require recorded consent and an OpenAI
  key in the Cairn MCP server’s environment. Conversation capture builds Cards
  locally. No saved conversation text is sent for extraction. Keyless installs
  send nothing to OpenAI. Run setup --local with OPENAI_API_KEY to record
  consent. If you add the key later, run setup --local again with the key to
  enable embeddings. Semantic search costs up to an estimated US$1 per day per
  running Cairn server.
The previous local engine uses a key from the MCP server’s environment. On that
  engine, saved conversations go to OpenAI only with --raw-semantic or an
  explicit --context-embedder configuration. On the previous engine,
  --no-context-semantic turns off embeddings only. With a key, recall and other
  model features can still send memory text to OpenAI.
