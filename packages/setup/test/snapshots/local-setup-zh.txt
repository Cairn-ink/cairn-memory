Cairn.ink Memory 安裝程式 <version>
1. 本機：資料留在這台電腦，免費、可離線使用，無法跨電腦同步。
2. 雲端：記憶可跨電腦和工具共用，需要登入 cairn.ink。
? 記憶要存在哪裡？(1/2)
記憶留在這台電腦，安裝程式不會傳送你的資料。
新版的本機引擎在儲存、更正或匯入記憶時，會把記憶文字傳給 OpenAI 並轉成
  embeddings。語意回想會傳送查詢文字來產生 embeddings。Cairn
  必須已記錄你的同意，而且 MCP server 的環境中有 OpenAI
  金鑰，才會送出這些請求。對話擷取會在本機建立卡片，不會把已保存的對話文字傳出去
  做擷取。無金鑰的安裝不會傳送任何資料給 OpenAI。在有設定 OPENAI_API_KEY
  的環境執行 setup --local，就會記錄你的同意。如果事後才加上金鑰，請帶著金鑰再跑
  一次 setup --local 才能啟用 embeddings。語意搜尋的費用，每個執行中的 Cairn
  server 每天預估上限約 US$1。
舊版的本機引擎會使用 MCP server 環境中的金鑰。舊版只有在用 --raw-semantic
  啟用，或明確設定 --context-embedder 時，才會把保存的對話傳給
  OpenAI。在舊版引擎上，--no-context-semantic 只會關閉
  embeddings。有金鑰時，回想和其他模型功能仍可能把記憶文字傳給 OpenAI。
