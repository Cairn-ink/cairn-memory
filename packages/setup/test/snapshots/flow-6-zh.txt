在這台電腦找到 Claude Code 和 Codex。

連接後，你和 AI 的對話會先在本機盡量遮掉密碼、金鑰等敏感資訊，再存到你的 Cairn。
每次提問時，也會送出一段遮過、有長度上限的提問，用來找回相關記憶。
Claude Code 外掛預設會送出使用統計，不含任何對話內容。
使用統計可以關閉，記憶也隨時可以暫停。完整說明：cairn.ink/memory/privacy
