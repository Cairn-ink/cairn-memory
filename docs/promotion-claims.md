# Cairn.ink Memory promotion claims and evidence

Reviewed **2026-11-13** against npm package **`@cairn-ink/memory` 0.6.6** and
source commit **`2238d2fc`**. This audits the current [English README](../README.md)
and its [Traditional Chinese counterpart](../README.zh-TW.md), using the release
source when the checkout differs. 0.6.6 was published to npm on 2026-11-13.

Release tag: [`installer-v0.6.6`](https://github.com/Cairn-ink/cairn-memory/tree/installer-v0.6.6).
GitHub Release: [@cairn-ink/memory 0.6.6](https://github.com/Cairn-ink/cairn-memory/releases/tag/installer-v0.6.6).
Release commit on main: [`2238d2fc`](https://github.com/Cairn-ink/cairn-memory/commit/2238d2fc7cac8dd7548266ad8279b1d9134bb812).

Evidence paths below refer to their contents at `2238d2fc` for 0.6.6 behavior,
including paths that arrive with the release merge. Test citations mean their
assertions were inspected, not that they were executed in this audit. Historical
records retain their stated versions. Public Cloud sources establish client and
wire contracts, not the private service's deployed behavior or quality.

## Supported paths

All **npx installer** paths require Node **`>=22.16.0`**, from the release's
[`engines.node`](../packages/setup/package.json), npm and the selected client CLI
on `PATH`. Local engine installation needs registry access or a populated cache.
The hosted plugin's separate runtime floor is Node 20; its manual install does
not use the npm installer's engine requirement.

## What we do not claim

- Model-extraction quality: the default source-support gate still fails; see [known limitations](limitations.md).
- Recall accuracy: narrow lifecycle checks are not an accuracy measurement.
- Cost or token savings: provider budget controls are not evidence of savings.
- A fully local model path: keyless storage/search is distinct from verified local model processing.
- Client coverage beyond the tested clients: host hooks, versions and platforms have their own limits.
