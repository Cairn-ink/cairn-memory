# Frozen source-loop controls development rubric

Four new synthetic development cases adapted from known categories, not blind or
held-out. Actual source-window capture with source-bound-v2 qualification,
keyless restart after each window, original source-evidence MOC recall, then
original decision-basis proposals for MOC refs, simple lexical refs and all
captured refs. No ideal-memory manual admission or rubric-based rescue.

Use the existing gpt-4.1-mini-2025-04-14 adapter for capture/select/rank and the
existing gpt-5.6-sol model for all three basis controls. This is the configured
pipeline, not a claim about best models. Original basis mode stays unchanged;
do not promote the negative addressed experiment. Identical selected sources
across controls can still produce model variance; do not attribute every change
to retrieval. Preserve all outcomes, including empty/failed capture, incomplete
classification, empty recall, oracle over six refs, failed basis and transport.

Coverage is exact source-message presence, not semantic accuracy. Separately
inspect each original message, admitted content, retained receipts, actual recall
receipts, selected-ref expansions, and raw proposed roles/links. Required source
IDs never go to model methods. Capture omissions are not retrieval failures;
missing MOC sources despite captured evidence are not interpretation failures.
The captured oracle cannot recover source messages that extraction discarded.
No final answer, ordered reconciliation, MCP consumer or real user is measured.

Case expectations:
1. Rill: removable-battery and rear-rack reasons separate; sealed battery changes
   only the former. Do not invent replacement or treat unchanged rack as a challenge.
2. Pickup: original17:00 choice supported by18:00 closing; new16:00 closing
   challenges current applicability and supports explicit15:00 pickup. Original
   closing time was historically correct; confirmation of that is not a challenge.
   Duplicated roles can represent this in original mode; missing new support is
   still an omission, not a clean success.
3. Reading: normal library/quiet and two-day cafe/noise reasons remain scoped.
   A two-day-scoped challenge to quiet applicability is valid; permanent change
   is not. Return/nonpermanent wording must not become a new contradictory choice.
4. Journal: preserve attributed mistaken belief, corrected by cloud-default fact.
   Assistant suggestion is not adopted; no Loom decision or diary-transfer
   authorization follows. Source memory itself never grants execution authority.

All interpretation judgments are nonblind agent review. Accept exact-but-wrong
proposals only as recorded unassessed outputs, never as semantic successes.
No retries or replacement cases. Before live execution, require a separately
reviewed pinned installed operator, one durable shared50USD ledger, exclusive
intent, phase-specific closed methods and explicit conservative per-run cap.
This fixture/rubric preparation alone does not enable any live calls.
