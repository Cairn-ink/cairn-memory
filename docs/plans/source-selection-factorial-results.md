## Design and observed outcomes

Two independently authored synthetic sessions (English board-game holds and
Traditional Chinese walking booklet) contain two chronological batches of six
alternating messages each: 24 original messages and four frozen minimal claims.
Ordinary indexed capture and source-selection capture each write once per
session. Default selection and the existing opt-in bounded-source-scan then
perform separate cold reads of that same snapshot. Four write groups produce
eight first answers; each cell has two answers, not eight independent questions.
Capture order alternates by session and read order by write-group ordinal.

All four writes and eight read/answers completed; zero failed or not-run.
Two captures per group applied normal classification revisions. The 26 final
memories retain actual content, receipts, source bindings, revision and order.
All eight before/after snapshots match their shared write snapshot; four owned
synthetic databases were cleaned. All scan cases actually used complete-map;
default used actual model selection. No forced all-memory answer was used.

Selected memories and packed source windows are different units. Retained map
pages, actual select outputs or deterministic scan selections, actual rank
inputs/outputs, returned receipts, packed evidence, packing omissions and
not-recalled windows expose each stage. More rank candidates produced no new
packed coverage. Differing extras under identical answer inputs cannot
establish a causal read-policy benefit.

Both independent nonauthor same-family AI reviews were fixed before explicit
cell mapping, with zero material scoring disagreements. All 16 initial rating
views remain unchanged in substance: eight answers and 16 minimal claims per
reviewer, with 100/85 exact quote checks. Representation may reveal mechanism,
so blindness and human ground truth are not established. The agreement retains
a transparent correction of an unverified manually typed timestamp; tool order
establishes agreement before explicit unmasking, not a verified exact timestamp.

Both unsupported extras remain:

- English candidate/default asserted installed signage. The full timeline
  confirms the sign, but actual answer input contained only proposed wording;
  the next message confirming installation was not recalled.
- Chinese baseline/scan added “招牌圖片排版也較簡單” as a choice rationale.
  Sources state picture allocation and portability, not that layout was simpler
  or that simplicity motivated A6.

These extras remain separate from minimal completeness. The frozen
candidate-scan feasibility condition passes 2/2 fully supported answers, but two
sessions cannot satisfy the existing net ≥3/24 formal quality gate. The primary
decision stops spending on small-set source-copy/read-scan variants and selects
bounded offline exploration of actual revisioned MOC L2/L1 routing, with unchanged
capture/receipts, final rank and answer policy. A realistic routing-opportunity
check must precede any separately frozen paid quality study.
