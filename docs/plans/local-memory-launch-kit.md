# Local memory launch-readiness kit

Dependency: local install-artifact branch, initial base
`4f46be2f4401249e78f040481134859740176680`, advanced to reviewed install candidate
`326809a518111d867f02035a7ad1b34cb9a67ab7`. Documentation and repeatable onboarding

## Acceptance L01–L07

- L01: Lead the repository README with the independently runnable local memory
  layer, not a hosted-client-only description. Clearly separate the released
  hosted Claude plugin from the unpublished local developer preview. Preserve
  working hosted instructions in a clearly marked section or linked guide.
- L02: Give a coherent route from source/build to isolated local installation,
  first explicit memory, inspection, new-process recall, correction and forgetting.
  Use the actual five tools and installed executable. State Node/npm/tar/provider
  prerequisites and link detailed commands. Do not invent a published npx command,
  automatic capture, remote endpoint, account requirement or fully local model.
- L03: State observable benefits and evidence, without competitor superiority,
  universal accuracy, unmeasured time/token savings or fabricated user outcomes.
  Frozen source-support evaluation is failed; disclose the concrete limitation
  next to evidence claims. Synthetic lifecycle success is not human adoption.
- L04: Explain storage vs cloud-model processing, best-effort redaction, receipt
  retention, logical deletion/backups, no hidden core telemetry and the separately
  released hosted plugin's different capture/telemetry defaults. Link security,
  license/dependency notices, architecture and contribution/testing instructions.
- L05: Add a reproducible short demo script/transcript with expected outcomes,
  explicitly distinguishing instructions from an actual recorded live run. No
  staged output presented as measured evidence; no model key committed or printed.
- L06: Freeze a small proposed PLG observation plan: first write + later-session
  useful sourced recall as activation, voluntary content-free feedback, a defined
  observation window, stars as secondary observation not promised target or gate.
  No real telemetry collection, email, post, issue or registry publication.
- L07: A context-free independent reader checks the documented no-key install,
  remember/inspect/correct/forget loop against an actual artifact using fresh
  synthetic data. Paid recall is DRI-only under the existing cumulative ceiling;
  reuse the separate recorded installed-host evidence rather than imply this
  reader ran a paid test. Report friction and unresolved host/model-quality gates.
  Repository/doc links and normal validation pass; final candidate receives
  independent Standards and Spec reviews before a dependent PR.

## Explicit non-goals

This package prepares a truthful developer-facing introduction. It cannot mark
the product ready for broad promotion while source-support evaluation is failed.
Hermes native-provider status must reflect its independently verified package,
not merely the existing MCP discovery test. OpenClaw and other untested clients,
Moss, a full UI, publication and commercial cutover remain out of this scope.
