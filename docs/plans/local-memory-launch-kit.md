## Explicit non-goals

This package prepares a truthful developer-facing introduction. It cannot mark
the product ready for broad promotion while source-support evaluation is failed.
Hermes native-provider status must reflect its independently verified package,
not merely the existing MCP discovery test. OpenClaw and other untested clients,
Moss, a full UI, publication and commercial cutover remain out of this scope.

isolated npm project and installed it with explicit prefix and scripts disabled.
