## Falsifiable alternatives

1. Source loss: missing necessary source can explain a failed case, but not a
   case whose complete necessary receipts reached the answer. This source-equal
   contrast cannot fix an upstream omission and must report it separately.
2. Overlay interference: unsupported model-generated edges/status may influence
   applicability. Withholding only that overlay should improve relevant answers
   without losing source evidence or harming valid controls.
3. Independent answer reasoning: the answerer may confuse a changed reason with
   cancelled adoption even without the overlay. Persistence of that error in B
   weakens the overlay hypothesis; it does not justify rewriting the sources.

Neither the closed first baseline nor earlier focus/basis experiments establish
which alternative causes a final answer. Primary selects this one bounded probe;
an actual GPT-6.1 Sol/high worker owns implementation, primary owns integration,
verification, fixed-diff independent review and any later one-use live operator.
