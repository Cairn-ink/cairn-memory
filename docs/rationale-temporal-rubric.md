## Scoring rules

Review all proposals against all retained sources. Separately record false
direction/scope, missed genuine challenges, missing independently supported
reasons, useful retractions, abstention, structural failures, latency and cost.
Do not turn an unavailable/rejected arm into an empty graph or exclude it from
the denominator. One attempt per arm; baseline and candidate see identical
retained sources in identical order under the same model and resource limits.

Self-support is permitted where the source explicitly contains a decision and
its reason. It does not substitute for coverage of a separately recorded
reason's evidence. A challenge to a premise embedded in a decision can be a
valid alternative to a challenge targeting its separate premise memory.
Historical support does not establish present capability. Source attribution
does not prove the source true. No decision replacement or execution permission
can be inferred merely from a challenged premise.

Not every disagreement needs a directed challenge: preserve unknown applicability
as unknown. Do not reward an empty graph that avoids errors by losing all useful
evidence. Judge genuinely supported alternative links, not exact tuple equality.
Historical rebuttal of a mistaken report is source-grounded but remains a noted
ontology limitation of the current `challenges-premise` label.
