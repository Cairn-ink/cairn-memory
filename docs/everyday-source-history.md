# Fresh everyday source-history gate

This protocol applies the existing bounded long-history driver to a new
synthetic 32-message history after the qualification mapping fix. It is an
unexecuted development gate, not a rerun or repaired score for the earlier
stopped experiment and not an observed model-quality result.

The [fixture](../evaluation/live/everyday-source-history-fixture.json) contains
eight four-message windows about a work-room decision whose reasons change, a
usual bakery collection day with one exception, separate actors, and a table
loan that moves from consideration to refusal. Four later questions produce
eight answer-arm slots. The
[source-ID rubric](../evaluation/live/everyday-source-history-rubric.json) and
[semantic rubric](everyday-source-history-rubric.md) remain separate from all
model-facing inputs.

The unchanged `runLongSourceHistory` driver performs explicit source-bound-v2
capture, warm and cold inspection, MOC source-evidence recall, a simple lexical
source control and bounded answers. It retains capture, restart, source coverage,
recall and answer failures without retry or manual source rescue. Source IDs
measure diagnostic passage retention and retrieval, not semantic answer accuracy;
legitimate repeated evidence may support an answer when one required ID is absent.
Other-person passages can be useful disambiguation rather than noise.

Offline coverage uses the real local core with scripted extraction,
qualification, MOC filing, selection and ranking. It must produce all eight
capture windows, four queries, eight MOC/lexical arms and eight unassessed answer
records. That test establishes orchestration and denominator retention only. It
does not establish semantic quality, natural host behavior, provider schema
compliance or MOC advantage.

Any paid execution requires separately frozen source, artifact, fixture, rubric
and operator pins, plus the existing durable US$50 ledger and all prior safety
gates. Its independent ceiling is at most 128 HTTP requests, eight host calls and
US$1.50 in conservative reservations, subject to remaining headroom. A failure
is retained and never retried. This document grants no credential access,
provider call, production change, package-default change or release claim.
