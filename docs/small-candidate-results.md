# Fixed-candidate retention: one useful improvement, not promotion

The once-only [frozen comparison](small-candidate-comparison.md) completed
eighteen provider requests and all eight ordinary host answers. Retaining a
small selected set recovered a changed-weight source and a faithful answer in
one case. It also exposed three labelled irrelevant passages in other cases.
Those added passages caused no evident substantive answer error in this run;
this does not establish their safety in general.

The policy remains **evaluation-only**. Four authored cases with fixed selection
cannot establish a reliable end-to-end memory layer or justify a new default.

## What actually ran

One synthetic local store per case, with complete source text admitted through
the trusted core API, reused unchanged by both arms. A scripted selector returned
all predeclared references. Actual shared-core recall used source evidence and
limit3. Baseline used the original ranker; candidate wrapped that rank port with
the bounded retention policy. The ordinary host answer instruction was unchanged.

All four paired ordered rank inputs were identical. Each store has retained
seed, before/after each arm, and final ordered list/full-record snapshots; they
matched. Final host source projections matched the original memory/revision and
receipt identities, roles, excerpts and counts. These checks establish the
mechanical comparison boundary, not factual truth or correct interpretation.

Both arms ranked the larger set independently. Small candidate arms made no rank
generation or provider input-count request. Successful empty recall still got an
answer. No failure was retried, repaired, replaced or removed from a denominator.
All cleanup completed, with zero unsettled requests. No installed artifact,
natural MCP-client session, extraction, semantic navigation or real user was
tested by this source-built diagnostic.

Before scoring, a genuine preflight showed that admission's existing NFKC
normalization changes fullwidth Chinese punctuation. The three Chinese source
passages were frozen with canonical punctuation and a regression assertion;
the operator still rejected any stored-text mismatch. This does not establish
fidelity for arbitrary normalization-sensitive text.

The concrete positive observation is c01: retaining the changed premise
accompanied a faithful answer instead of an obsolete reason. Source set, order
and independent host generation also differ between arms; this is not a causal
isolation of the added passage alone. Do not convert eight completed answers
into an aggregate accuracy percentage.

The primary reviewer read every actual source view and answer. Two additional
reviews were conducted without consulting each other's judgments. One reviewer
authored the fixture/rubric and retention wrapper; the other authored the private
operator. Neither authored the provider answers. All reviews were nonblind and
same-family, not independent human or cross-model evaluation.

This run avoided three rank generations and three count requests, while adding
1538 source bytes and479 local source tokens. Wall times include verification
and/or local processing as well as network/provider time; these are observed
single-run totals, not a latency benchmark or generalized savings guarantee.

The existing campaign moved from1809 to1827 requests and fromUS$21.896 to
**US$22.346 conservatively reserved**, an increment ofUS$0.450 within this run's
US$1 ceiling. Known usage estimate increased byUS$0.004786 toUS$1.216239; it is
not an invoice. All five provider input-count calls have unknown cost, increasing
the retained unknown-cost count from845 to850. Their reservations remain held;
they are not free or refunded. Zero requests are unsettled. Conservative
headroom within the existing US$50 campaign isUS$27.654. Older campaigns are
separate and do not create renewed allowance.

## Decision and next step

Keep the wrapper evaluation-only. Proceed to a fresh end-to-end comparison on
ordinary MOC selection with multi-window histories and distractors, using the
same actual stores across arms. Report when this small-set policy does not apply,
and separate admission, navigation, ranking and host-interpretation failures.
Retain currently useful sources and test irrelevant/empty cases as well as
changed reasons. Only broader evidence can support integration or default
promotion. No package release, deployment or new paid run is authorized by
this result document.
