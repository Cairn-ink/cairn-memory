# Rationale comparison operator notes

This is a synthetic evaluation operator, not a user setup command. The product
configuration is documented in [the automatic loop guide](automatic-rationale-loop.md).

## Offline installed gate

Use Node 22.16 or 24 and CONTRIBUTING.md dependency preparation:

```sh
npm ci --prefix adapters/openai
npm ci --prefix adapters/mcp
node packaging/prepare-cache.mjs
CAIRN_RATIONALE_INSTALLED_OFFLINE=1 node --test evaluation/live/test/rationale-pilot.test.mjs
```

Only cache preparation makes public registry metadata requests. Tests build a
private archive, explicitly install it offline into a fresh temporary prefix,
and run actual MCP/adapter/core code against fake HTTP and synthetic ledgers.
Without the explicit flag, the ordinary live-offline suite runs the preflight
test and skips three installed cases. CI runs the explicit gate in both MCP jobs.
Scripted self-links in the test double are intentionally semantic-blind; their
passing result is not evidence that those relationships are correct.

## Reviewed one-shot live entry point

`evaluation/live/rationale-pilot.mjs` exports `getRationalePilotPins()` and
`runRationalePilot(options)`. Exact options are ledger, expectedCheckpoint,
apiKey, fetchImpl, nodePath, cairnExecutable, cairnArtifact,
cairnArtifactSha256, privateDirectory, pins and rationaleExtension.

The trusted operator supplies a previously authorized, settled cumulative
ledger and a separate rationale token with authorizationId `rationale-pilot-v1`.
The runner never discovers credentials, provisions that token, resets the
ledger or starts a paid call on import. Supply a one-attempt transport with no
hidden retries. Verify the exact reviewed code/artifact/pins and actual remaining
budget first. The 384-HTTP/US$1.92 ceiling is conservative reserved allowance,
not a quoted invoice; the fixed sixteen-arm schedule additionally caps each
phase (6 baseline capture, 8 candidate capture, 4 recall), at most 288 HTTP.

The provider snapshot remains `gpt-4.1-mini-2025-04-14` in both arms. On
2026-09-14, official [model documentation](https://developers.openai.com/api/docs/models/gpt-4.1-mini)
lists standard input/output prices US$0.40/US$1.60 per million tokens, matching
the existing baseline policy. Input-count requests retain unknown actual cost;
neither successful counting nor unused reservations establish a zero charge.

Before any request, the runner claims an exclusive ledger-scoped intent. Its
presence prevents a second invocation with a new output directory. Never remove
or rename the intent to rerun a failed case. A missing response retains its
reservation; subsequent scheduled arms remain not-run in the denominator.
All detailed artifacts are private synthetic traces, including local paths.
Do not publish `final-report.json` directly: prepare a scrubbed source-linked
export and independent semantic assessment first.

## Interpretation

Eight cases compare source evidence with proposed rationale evidence. Choice,
reason, changed premise, attribution, uncertainty and source fidelity are judged
independently against frozen sources and evaluator-only rubrics. An empty graph
is not a successful positive detection; a failed recall is not an accurate
answer. No host answer is generated by this pilot. Small synthetic observations
do not establish real-user reliability or competitor superiority.

See the [frozen contract](plans/rationale-installed-pilot.md). No registry
publication, deployment, production data access or automatic repair is included.
